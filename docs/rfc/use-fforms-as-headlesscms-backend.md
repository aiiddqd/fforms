# Use case - FForms as backend for headless CMS with REST API

## Предпосылки
- ок модель есть и даже констурктор форм
- но надо чтобы формы можно было добавлять программно, типа fforms_add_api_route(...)
- суть в том что минимально надо указать какие поля нужны для формы и ее название и ключ
    - название - человеко понятное
    - ключ - уникальный идентификатор формы, используемый в API
- цель - после регистрации появляется роут для работы с формой через REST API - прием заявок с фронтенда типа AstroJS
