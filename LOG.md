# LOG

Журнал изменений плагина в обратном хронологическом порядке (новое — сверху).
Каждая запись — одна строка: дата, краткое описание сути изменения.

Формат записи:

```
## YYYY-MM-DD
- краткое описание изменения
- ...
```

## 2026-08-30

- Откатена интеграция `.env` с wp-env: debug-константы снова заданы в `.wp-env.json`, а `.env` остаётся для тестов и других инструментов.
- Подключена сборка общих, editor- и runtime-стилей блока формы, чтобы preview в Gutenberg использовал вертикальную раскладку и стили состояний.
- Добавлен Playwright smoke test для шаблона новой формы: загрузка CSS, вертикальное расположение label/control и активная кнопка отправки.
- В RFC отмечена пройденная проверка добавления новой формы в Gutenberg.
- Игнорированы временные артефакты Playwright, создаваемые при падении e2e-тестов.
- Добавлена служебная запись о запрете рекурсивного удаления временных Playwright-артефактов в текущем окружении.
- Команда `test:e2e` теперь вызывает Playwright напрямую и использует конфигурацию локального WordPress-сайта.
- Явно добавлена dev-зависимость Playwright, требуемая e2e-конфигурацией.
- Зафиксировано, что проверка SCSS выполняется через `wp-scripts`, так как standalone Stylelint не имеет конфигурации проекта.
- Зафиксированы существующие ошибки `lint:pkg` в release-метаданных `package.json` для отдельной задачи.
- Перенесено включение уведомления о заявках в настройки конкретной формы; глобальная настройка теперь только активирует настройки уведомлений и автоответов.
- Обновлены базовая спецификация и roadmap для per-form уведомлений, выключенных по умолчанию.
- Зафиксирована недоступность runtime-проверки: локальный контейнер wp-env остановлен.
